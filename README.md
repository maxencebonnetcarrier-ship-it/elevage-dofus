# Élevage Dragodindes — Ombre (Dofus 3.7)

Page de calcul pour l'élevage de dragodindes : chemin le plus rapide vers la génération 10, niveau optimal des parents, dernier croisement (gén. 9 × gén. 1 ou Prune × Émeraude), prix des crafts et brisage Muldo / Volkorne.

- Ouvrir `index.html` dans un navigateur : tout tourne dans la page, sans serveur.
- Les prix et réglages saisis sont gardés dans le navigateur (stockage local).
- Tests : `node test-engine.js` (moteur de calcul) et `node ui-test.mjs file:///…/index.html` (interface, Chrome sans fenêtre).

Règles : dofuspourlesnoobs.com, dofuselevage.fr (modèle de répartition des issues, non officiel), sigilos.fr, next-stage.fr. Recettes : DofusDB. Table d'XP et idée du calcul en cascade : muldo-calculator (Chikkin Sama).
